# Design Documentation

This folder houses living documents that guide Ithas Fire's brand and interface experiences.

- **`design-system-v2.md` – ⭐ THE SOURCE OF TRUTH for all UI work.** Token architecture, the
  v2-name→code-token mapping, theme keys, non-negotiables, flex-vs-grid, icon grammar,
  sanctioned organisms, S1–S7 section slots, budgets. Read this first.
- **`ithasfire-design-system-v2.html`** – Browsable/themeable companion to the above. Open in a
  browser and flip the Ember/Stub toggle to see the whole system reskin.
- `style-guide.md` – Typography, spacing, motion, and voice. ⚠️ Its **palette** and **dark-mode**
  sections are **superseded by `design-system-v2.md`** — do not take colors from it.

> Each document is intentionally lightweight to encourage regular updates as we learn and evolve the product.
