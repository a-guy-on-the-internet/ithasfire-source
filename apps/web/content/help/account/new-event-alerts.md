When you follow an organiser, a person's page or a place, Ithas Fire can tell you when that page has a new event. This article explains which events send an alert and which never do. To follow or unfollow a page, see [following organisers and places](/help/account/following-organisers-and-places).

## What sends an alert

You get an alert when an event is published for the first time and a page you follow put its own name on it:

- **The organiser.** The organisation that runs the event, or the person whose own event it is.
- **The place**, but only when the place stands behind the event: it is the place's own show, or the place has confirmed it.

A place confirming an event that is already live also sends an alert, to the place's followers only.

Alerts go out in batches, usually within about half an hour of the event being published. An event that starts before its alert goes out is dropped, not sent late.

## You get one alert per event

If you follow the organiser and the place of the same event, you still get one alert, not two.

## What never sends an alert

- **Events with an access gate.** A password-protected event, or one behind an application, never sends an alert. See [restrict access to an event](/help/organising-events/restrict-event-access).
- **Private events.** Only events set to **Public** are announced.
- **Publishing the same event again.** Unpublishing an event and publishing it again does not send a second alert.
- **Events that have already started.**
- **Lineup acts.** Being added to an event's lineup does not alert that act's followers. Only the organiser and the place can trigger an alert.
- **Community listings the place did not vouch for.** A community listing at a place that takes community listings does not alert the place's followers. The place has to have confirmed that listing.
- **Places that hide their address.** A place set to show only an area, not its exact address, sends no alerts. See [obscured locations and address reveal](/help/organising-events/hidden-places-and-address-reveal).
- **Pages you followed after the event was announced.** Following a page does not bring you alerts for its earlier announcements.

## Only events near you

A follow can be limited to events near you. The distance limit is 100 km unless you set a different one.

To measure the distance, Ithas Fire needs two points, and both must already be public:

- **Your point** is the public address of the most recent event you bought tickets for. An event at a place that hides its address, an event with a hidden location, or an event with an access gate is skipped, and the one before it is tried, back through your ten most recent ticket orders.
- **The new event's point** is its public address.

If either point is not public, you get no alert for that event. Your nearby setting never gets matched against an address that is hidden.

## Where alerts arrive

Alerts can arrive in the app, by email and by push notification. They never arrive by SMS. Which of these you get is set by the **Organizer updates** category in [Settings → Notifications](/account/settings/notifications). See [notification settings](/help/account/notification-settings).

## Turn alerts off

- **For one page:** open the page and click the **Follow** button again to unfollow.
- **For every page:** in [Settings → Notifications](/account/settings/notifications), switch off the channels under **Organizer updates**. This category also covers other messages from organisers, such as announcements.

Every alert email ends with a link to your notification settings.
